# Adivina el Número

Proyecto desarrollado en Python donde el computador intenta adivinar un número pensado por el usuario utilizando búsqueda binaria.

## Características

- Arquitectura modular.
- Separación por responsabilidades.
- Uso de búsqueda binaria.
- Control de intentos.
- Gestión de estado del juego.

## Estructura

- estado/
- intentos/
- interfaz/
- logica/
- rangos/
